02 / THE CORE IDEA

First in, first out

A queue serves items in arrival order. The earliest arrival leaves first: FIFO.

The cafeteria line

Students join at the rear. Lunch is served at the front. A new arrival does not teleport to the counter—unless they want a lecture on both manners and asymptotic behavior.

Queue vs. stack

Queue: FIFO—oldest item leaves first.

Stack: LIFO—newest item leaves first.

Two important errors

Underflow: dequeue from empty.

Overflow: enqueue into a full fixed-capacity queue.

04 / IMPLEMENTATION A

Linear array queue

Two indices do the bookkeeping: frontIndex points to the next item to remove; rearIndex points to the last inserted item.

Start empty

Set both indices to −1. This sentinel means “no valid position yet.”

First enqueue

Move both indices to 0, then store the first value.

Later enqueues

Increment rearIndex, then place the value there.

Dequeue

Read the front value, then increment frontIndex. If it passed the rear, reset both indices.

linear_queue.cpp · complete program
#include <iostream>
using namespace std;

class ArrayQueue {
private:
    static const int CAPACITY = 5;
    int data[CAPACITY];
    int frontIndex;
    int rearIndex;

public:
    // A new queue contains no valid indices.
    ArrayQueue() : frontIndex(-1), rearIndex(-1) {}

    bool isEmpty() const {
        return frontIndex == -1;
    }

    bool isFull() const {
        return rearIndex == CAPACITY - 1;
    }

    void enqueue(int value) {
        if (isFull()) {
            cout << "Queue overflow: no space left.\n";
            return;
        }
        if (isEmpty()) frontIndex = 0;
        data[++rearIndex] = value;
    }

    bool dequeue(int& removedValue) {
        if (isEmpty()) {
            cout << "Queue underflow: nothing to remove.\n";
            return false;
        }
        removedValue = data[frontIndex++];

        // The final element was removed: restore empty state.
        if (frontIndex > rearIndex) {
            frontIndex = rearIndex = -1;
        }
        return true;
    }

    bool front(int& value) const {
        if (isEmpty()) return false;
        value = data[frontIndex];
        return true;
    }

    void display() const {
        if (isEmpty()) {
            cout << "[empty]\n";
            return;
        }
        cout << "Front -> ";
        for (int i = frontIndex; i <= rearIndex; ++i)
            cout << data[i] << ' ';
        cout << "<- Rear\n";
    }
};

int main() {
    ArrayQueue q;
    q.enqueue(10);
    q.enqueue(20);
    q.enqueue(30);
    q.display();

    int removed;
    if (q.dequeue(removed))
        cout << "Removed: " << removed << '\n';

    q.display();
    return 0;
}
The linear-array limitation

After dequeues, unused cells may exist before frontIndex, but rearIndex cannot move past the final array cell. The queue may report “full” while space sits unused at the beginning. We can shift every item—slow—or make the indices wrap around—smart.

05 / IMPLEMENTATION B

Circular queue

A circular queue treats the last array position as adjacent to the first. Modular arithmetic makes the wrap-around precise.

Wrap-around formula

for capacity = N

next = (current + 1) % N

If current = 4 and N = 5, then (4 + 1) % 5 = 0. The index returns to the beginning—no teleportation, just remainder arithmetic.

Track the count

count == 0 means empty; count == CAPACITY means full. No ambiguous index gymnastics.

Insert, then wrap

Store at rearIndex, then set rearIndex = (rearIndex + 1) % CAPACITY.

Remove, then wrap

Read at frontIndex, then advance it with the same formula.

circular_queue.cpp · reusable template
#include <iostream>
using namespace std;

template <typename T, int CAPACITY>
class CircularQueue {
private:
    T data[CAPACITY];
    int frontIndex = 0; // Next item to remove
    int rearIndex = 0;  // Next free slot
    int count = 0;

public:
    bool isEmpty() const { return count == 0; }
    bool isFull() const { return count == CAPACITY; }
    int size() const { return count; }

    bool enqueue(const T& value) {
        if (isFull()) return false;

        data[rearIndex] = value;
        rearIndex = (rearIndex + 1) % CAPACITY;
        ++count;
        return true;
    }

    bool dequeue(T& removedValue) {
        if (isEmpty()) return false;

        removedValue = data[frontIndex];
        frontIndex = (frontIndex + 1) % CAPACITY;
        --count;
        return true;
    }

    bool front(T& value) const {
        if (isEmpty()) return false;
        value = data[frontIndex];
        return true;
    }

    void display() const {
        cout << "Front -> ";
        for (int i = 0; i < count; ++i) {
            int index = (frontIndex + i) % CAPACITY;
            cout << data[index] << ' ';
        }
        cout << "<- Rear\n";
    }
};

int main() {
    CircularQueue<int, 5> q;
    q.enqueue(10); q.enqueue(20); q.enqueue(30);

    int removed;
    q.dequeue(removed); // Removes 10
    q.enqueue(40); q.enqueue(50); q.enqueue(60);
    q.display();       // 20 30 40 50 60
    return 0;
}

linked_queue.cpp · complete program
#include <iostream>
using namespace std;

class LinkedQueue {
private:
    struct Node {
        int value;
        Node* next;
        Node(int v) : value(v), next(nullptr) {}
    };

    Node* frontPtr = nullptr;
    Node* rearPtr = nullptr;

public:
    // Destructor prevents memory leaks.
    ~LinkedQueue() {
        int ignored;
        while (dequeue(ignored)) { }
    }

    bool isEmpty() const {
        return frontPtr == nullptr;
    }

    void enqueue(int value) {
        Node* newNode = new Node(value);

        if (isEmpty()) {
            frontPtr = rearPtr = newNode;
        } else {
            rearPtr->next = newNode;
            rearPtr = newNode;
        }
    }

    bool dequeue(int& removedValue) {
        if (isEmpty()) return false;

        Node* oldFront = frontPtr;
        removedValue = oldFront->value;
        frontPtr = frontPtr->next;
        delete oldFront;

        // If the queue became empty, rear must also be null.
        if (frontPtr == nullptr) rearPtr = nullptr;
        return true;
    }

    bool front(int& value) const {
        if (isEmpty()) return false;
        value = frontPtr->value;
        return true;
    }
};

int main() {
    LinkedQueue q;
    q.enqueue(7); q.enqueue(14); q.enqueue(21);

    int value;
    while (q.dequeue(value))
        cout << "Serving: " << value << '\n';
    return 0;
}

Linear array

  • Simple and cache-friendly
  • Fixed size
  • Can waste freed front cells

Circular array

  • Reuses every slot
  • Fixed maximum size
  • Excellent for buffers

Linked list

  • Grows dynamically
  • Extra pointer per node
  • Allocation can fail
07 / THE STANDARD LIBRARY

Use std::queue

When the task is to solve a problem—not reimplement the structure—use the tested adapter in <queue>.

stl_queue.cpp · complete program
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    queue<string> helpDesk;

    helpDesk.push("Ticket A: Wi-Fi issue");  // enqueue
    helpDesk.push("Ticket B: Login issue");
    helpDesk.push("Ticket C: Printer issue");

    cout << "Waiting: " << helpDesk.size() << '\n';

    while (!helpDesk.empty()) {
        cout << "Handling: " << helpDesk.front() << '\n';
        helpDesk.pop(); // dequeue; pop() returns no value
    }
    return 0;
}

Safety habit

front(), back(), and pop() require a non-empty queue. Check empty() first. C++ trusts you; sometimes with the confidence of a friend who definitely did not read the assignment.

08 / WHY QUEUES MATTER

Queues in the wild

Queues appear wherever order, fairness, or delayed processing matters.

Printer spooler

Print jobs wait in arrival order. Add with push(); process the oldest with front() and pop().

Breadth-first search

BFS visits all neighbors before moving deeper. The queue stores vertices discovered but not yet explored.

Customer support

Tickets enter at the rear and agents handle the front ticket. Priority queues adapt the rule for emergencies.

Network buffers

Packets wait while a device processes earlier arrivals. Circular queues are especially useful for bounded buffers.

BFS example: shortest hops in an unweighted graph

bfs.cpp · queue in an algorithm
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

void bfs(const vector<vector<int>>& graph, int start) {
    vector<bool> visited(graph.size(), false);
    queue<int> pending;

    visited[start] = true;
    pending.push(start);

    while (!pending.empty()) {
        int current = pending.front();
        pending.pop();
        cout << current << ' ';

        for (int neighbor : graph[current]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true; // Mark before enqueue.
                pending.push(neighbor);
            }
        }
    }
}

int main() {
    vector<vector<int>> graph = {
        {1, 2}, {0, 3}, {0, 4}, {1}, {2}
    };
    bfs(graph, 0); // Output: 0 1 2 3 4
}
09 / DEBUG CLINIC

Classic queue bugs

Most queue bugs are boundary bugs wearing a tiny fake mustache. Catch them with invariants and edge cases.

BUG 01

Removing before checking

Accessing front() on an empty queue is invalid.

Fix: test isEmpty()/empty() first.

BUG 02

Rear not reset

After deleting the final linked node, rearPtr still points to freed memory.

Fix: set rearPtr = nullptr.

BUG 03

Wrong full condition

Index equality in a circular queue can mean empty or full.

Fix: track count, or deliberately reserve one slot.

BUG 04

Memory leak

A linked queue removes nodes but never calls delete.

Fix: save old front, advance, delete old front.

Minimum edge-case test set

  • Dequeue from an empty queue.
  • Enqueue exactly one item, then dequeue it.
  • Fill a bounded queue to capacity, then try one extra enqueue.
  • Wrap a circular queue past the final index.
  • Alternate enqueue and dequeue several times.
  • Destroy a non-empty linked queue; run with AddressSanitizer if available.
