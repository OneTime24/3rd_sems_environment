1 The Analogy: A Stack of Plates

Before we talk about memory and pointers, let's talk about lunch.

⬆️
⬇️
Only the TOP plate is reachable

Imagine a cafeteria stack of plates. The dishwasher places clean plates on top, one at a time. Customers take plates from the top, one at a time.

  • The last plate placed on the pile is the first one taken off.
  • You cannot pull out the third plate from the bottom without removing everything above it.
  • If the pile reaches the ceiling — you can't add any more. That's overflow.
  • If the pile is empty and someone tries to take a plate — that's underflow.
🔑 The One Rule A stack is a LIFO structure: Last In, First Out. All insertion and deletion happen at one single end, called the top.

3 The Five Core Operations

Every stack in every language supports these five operations. Learn them once, use them forever.

OperationWhat it doesPre-conditionTime
push(x) Places x on top of the stack and moves top up by 1. Stack must not be full O(1)
pop() Removes and returns the top element, then moves top down by 1. Stack must not be empty O(1)
peek() / top() Returns the top element without removing it. Stack must not be empty O(1)
isEmpty() Returns true if the stack has zero elements. None O(1)
isFull() Returns true if the stack has reached its capacity (array version only). None O(1)
⚠️ The Two Classic Errors Stack Overflow = you called push() on a full stack.
Stack Underflow = you called pop() or peek() on an empty stack.
Always check before you act. Every professional implementation does.

🔍 Important detail people miss After pop(), the old value (like 30 at index 2) is still physically in the array. We simply moved top down. The value is now "logically deleted" and will be overwritten by the next push. This is why pop is O(1) — no shifting, no erasing, just move a pointer.

4 Implementation 1 — Array-Based Stack

The simplest and fastest stack. An array + one integer called top.

🧠 The Idea in One Picture

Picture a row of lockers numbered 0 to N-1. A sticky note called top tells you which locker holds the current top element. When the stack is empty, top = -1 — a sentinel meaning "nowhere".

Statetopsize()isEmpty()isFull()
Empty (capacity 5)-10truefalse

💡 Two magic formulas size() == top + 1   •   isFull() == (top == CAPACITY - 1)

💻 Complete, Working C++ Code

stack_array.cpp 
#include <iostream>
using namespace std;

const int CAPACITY = 5;      // maximum number of elements we can store

class Stack {
private:
    int data[CAPACITY];      // the array that actually holds the elements
    int top;                 // index of the TOP element; -1 means "empty"

public:
    // ---------- CONSTRUCTOR ----------
    Stack() {
        top = -1;            // a brand new stack is empty
    }

    // ---------- isEmpty ----------
    bool isEmpty() {
        return (top == -1);
    }

    // ---------- isFull ----------
    bool isFull() {
        return (top == CAPACITY - 1);
    }

    // ---------- PUSH : add to the top ----------
    void push(int value) {
        if (isFull()) {
            cout << "Stack Overflow! Cannot push " << value << endl;
            return;                    // do nothing, stack is full
        }
        top++;                         // move top one step UP
        data[top] = value;             // store the value there
    }

    // ---------- POP : remove from the top ----------
    int pop() {
        if (isEmpty()) {
            cout << "Stack Underflow! Nothing to pop." << endl;
            return -1;                 // sentinel value meaning "error"
        }
        int value = data[top];         // 1. remember the top value
        top--;                         // 2. move top one step DOWN
        return value;                  // 3. hand the value back
    }

    // ---------- PEEK : look without removing ----------
    int peek() {
        if (isEmpty()) {
            cout << "Stack is empty. Nothing to peek." << endl;
            return -1;
        }
        return data[top];
    }

    // ---------- SIZE ----------
    int size() {
        return top + 1;
    }

    // ---------- DISPLAY (top -> bottom) ----------
    void display() {
        if (isEmpty()) {
            cout << "Stack: [ empty ]" << endl;
            return;
        }
        cout << "Stack (top -> bottom): ";
        for (int i = top; i >= 0; i--) {
            cout << data[i] << " ";
        }
        cout << endl;
    }
};

// ================= MAIN =================
int main() {
    Stack s;

    s.push(10);
    s.push(20);
    s.push(30);
    s.display();                            // 30 20 10

    cout << "Top element : " << s.peek()  << endl;   // 30
    cout << "Size        : " << s.size()  << endl;   // 3

    cout << "Popped      : " << s.pop()   << endl;   // 30
    s.display();                            // 20 10

    cout << "isEmpty?    : " << (s.isEmpty() ? "Yes" : "No") << endl;

    s.pop();  s.pop();                      // empty it
    s.pop();                                // -> Stack Underflow!

    return 0;
}

🔬 Line-by-Line: What Happens on push(30)?

  1. isFull() is called → top == CAPACITY - 1? Suppose top = 1, so it's false. Continue.
  2. top++ → top becomes 2.
  3. data[2] = 30 → the value is stored.
  4. Done. Total work: a comparison, an increment, and one array write. Constant time. O(1).

🔬 Line-by-Line: What Happens on pop()?

  1. isEmpty() is called → top == -1? No. Continue.
  2. value = data[top] → save 30 into a local variable.
  3. top-- → top becomes 1.
  4. return value → 30 is returned.
  5. Note: data[2] still contains 30 physically, but it is now outside the stack. It'll be overwritten on the next push.
⚠️ Limitation of the array version The capacity is fixed at compile time. If you need 10,000 elements but declared 5, you're stuck. The fix is either (a) a dynamic array with new/delete and resizing, or (b) a linked list — which is the next section.

5 Implementation 2 — Linked-List Stack

Unlimited size, no overflow (until your RAM runs out). The top of the stack is simply the head of the list.

🧠 The Idea

A linked list is a chain of nodes, where each node points to the next. If we say "the head of the list is the top of the stack", then:

  • push(x) = insert a new node at the head → O(1)
  • pop() = delete the node at the head → O(1)
  • peek() = read head->data → O(1)
💡 Why the head and not the tail? Inserting/deleting at the head is O(1). Inserting/deleting at the tail of a singly linked list requires walking the whole list — O(n). Always use the head as the top.

🎨 Visual: push(30) then push(40)

memory diagram
BEFORE push(30):
    top -> [20 | next] -> [10 | next] -> NULL

AFTER push(30):          (new node inserted at the head)
    top -> [30 | next] -> [20 | next] -> [10 | next] -> NULL

AFTER push(40):
    top -> [40 | next] -> [30 | next] -> [20 | next] -> [10 | next] -> NULL

AFTER pop():             (head removed and deleted)
    top -> [30 | next] -> [20 | next] -> [10 | next] -> NULL
    (the node holding 40 has been freed)

💻 Complete, Working C++ Code

stack_linkedlist.cpp 
#include <iostream>
using namespace std;

// ---------- A single node of our linked list ----------
struct Node {
    int   data;      // the value stored
    Node* next;      // pointer to the node below it in the stack
};

class LinkedStack {
private:
    Node* top;       // points to the TOP node (the head of the list)

public:
    // ---------- CONSTRUCTOR ----------
    LinkedStack() {
        top = nullptr;                 // empty stack
    }

    // ---------- DESTRUCTOR : free all memory ----------
    ~LinkedStack() {
        while (!isEmpty()) {
            pop();                     // pop() already deletes the node
        }
    }

    // ---------- isEmpty ----------
    bool isEmpty() {
        return (top == nullptr);
    }

    // ---------- PUSH : insert at the head ----------
    void push(int value) {
        Node* newNode = new Node;      // 1. create a new node on the heap
        newNode->data = value;         // 2. store the value
        newNode->next = top;           // 3. new node points to the OLD top
        top = newNode;                 // 4. the new node becomes the new top
        // No isFull() check needed - the list grows as long as memory exists!
    }

    // ---------- POP : delete the head ----------
    int pop() {
        if (isEmpty()) {
            cout << "Stack Underflow! Nothing to pop." << endl;
            return -1;
        }
        Node* temp = top;              // 1. remember the node we are removing
        int value = temp->data;        // 2. save its data
        top = top->next;               // 3. move top down to the next node
        delete temp;                   // 4. FREE the memory (very important!)
        return value;                  // 5. return the data
    }

    // ---------- PEEK ----------
    int peek() {
        if (isEmpty()) {
            cout << "Stack is empty." << endl;
            return -1;
        }
        return top->data;
    }

    // ---------- SIZE : count the nodes ----------
    int size() {
        int count = 0;
        Node* current = top;
        while (current != nullptr) {
            count++;
            current = current->next;
        }
        return count;                  // O(n) - walk the whole list
    }

    // ---------- DISPLAY ----------
    void display() {
        if (isEmpty()) {
            cout << "Stack: [ empty ]" << endl;
            return;
        }
        cout << "Stack (top -> bottom): ";
        Node* current = top;
        while (current != nullptr) {
            cout << current->data << " ";
            current = current->next;
        }
        cout << endl;
    }
};

// ================= MAIN =================
int main() {
    LinkedStack s;

    s.push(10);
    s.push(20);
    s.push(30);
    s.display();                             // 30 20 10

    cout << "Top   : " << s.peek() << endl;   // 30
    cout << "Size  : " << s.size() << endl;   // 3

    cout << "Popped: " << s.pop() << endl;    // 30
    s.display();                             // 20 10

    return 0;
}

⚖️ Array vs Linked List — Which Should You Use?

AspectArray-Based StackLinked-List Stack
SizeFixed at compile timeGrows dynamically
Overflow possible?Yes (when full)Only when RAM is exhausted
push / pop timeO(1)O(1)
Memory per element4 bytes (just the int)4 bytes + 8 bytes pointer = 12 bytes
Memory locality (cache)Excellent (contiguous)Poor (scattered on heap)
Risk of leaksNoneHigh — you must delete
Best forKnown, small, fixed sizesUnknown or large sizes
🚨 The #1 student mistake Forgetting delete temp; inside pop(). Without it, every pop leaks memory. A loop of a million pushes and pops will eat gigabytes. Always delete what you remove.

6 The Easy Way — C++ STL std::stack

In real projects you don't write your own stack — you use the Standard Template Library. Here's how.

stl_stack.cpp 
#include <iostream>
#include <stack>          // <-- the STL stack header
using namespace std;

int main() {
    stack<int> s;                 // declare a stack of integers

    // ---------- PUSH ----------
    s.push(10);
    s.push(20);
    s.push(30);

    // ---------- TOP (this is STL's name for peek) ----------
    cout << "Top  : " << s.top()  << endl;   // 30
    cout << "Size : " << s.size() << endl;   // 3

    // ---------- POP (returns void in STL!) ----------
    s.pop();                                   // removes 30, returns nothing
    cout << "New top after pop: " << s.top() << endl;  // 20

    // ---------- EMPTY ----------
    cout << "Empty? " << (s.empty() ? "Yes" : "No") << endl;

    // ---------- Print the whole stack (must pop to see everything) ----------
    cout << "Contents: ";
    while (!s.empty()) {
        cout << s.top() << " ";
        s.pop();
    }
    cout << endl;

    return 0;
}

📋 STL Stack Cheat-Sheet

STL CallMeaningNote
stack<int> s;Create an empty stack of intsTemplate — works with any type
s.push(x);Add x on topO(1)
s.pop();Remove the top elementReturns void! Call top() first if you need the value
s.top();Read the top elementThis is STL's peek()
s.empty();true if emptyAlways check before pop()/top()
s.size();Number of elementsReturns size_t
⚠️ The STL trap that catches everyone s.pop() does not return the removed value. If you want it, you must write:
int v = s.top(); s.pop();  — in that order.

💻 The C++ Code Behind It

balanced_brackets.cpp 
#include <iostream>
#include <stack>
#include <string>
using namespace std;

bool isBalanced(string expr) {
    stack<char> st;

    for (char c : expr) {

        // 1. Opening bracket -> push it and hope to match it later
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        }
        // 2. Closing bracket -> it MUST match whatever is on top
        else if (c == ')' || c == ']' || c == '}') {

            if (st.empty()) return false;        // nothing to match -> unbalanced

            char topChar = st.top();

            if ((c == ')' && topChar != '(') ||
                (c == ']' && topChar != '[') ||
                (c == '}' && topChar != '{')) {
                return false;                    // wrong type of bracket -> unbalanced
            }

            st.pop();                            // matched! remove it
        }
        // 3. Any other character (letters, digits, operators) -> just ignore
    }

    // 4. At the very end, the stack MUST be empty
    return st.empty();
}

int main() {
    string tests[] = {"{[A+(B*C)]-D}", "(A+B)", "((A+B)", "A+B)", "{[}]"};

    for (string t : tests) {
        cout << (isBalanced(t) ? "BALANCED   " : "UNBALANCED ") << "  " << t << endl;
    }
    return 0;
}
output

7.2 🔄 Infix → Postfix Conversion

Humans write A + B (infix). Computers prefer A B + (postfix), because postfix needs no parentheses and no precedence rules when evaluating. A stack of operators makes the conversion trivial.

📏 Operator precedence used ^ (3) > * / % (2) > + - (1)
infix_to_postfix.cpp 
#include <iostream>
#include <stack>
#include <string>
#include <cctype>
using namespace std;

// Returns how "powerful" an operator is
int precedence(char op) {
    if (op == '^')                          return 3;
    if (op == '*' || op == '/' || op == '%') return 2;
    if (op == '+' || op == '-')             return 1;
    return 0;   // not an operator
}

string infixToPostfix(string infix) {
    stack<char> st;          // stack of OPERATORS
    string postfix = "";     // the result we build

    for (char c : infix) {

        if (isalnum(c)) {                    // RULE 1: operand -> output directly
            postfix += c;
        }
        else if (c == '(') {                 // RULE 2: '(' -> push it
            st.push(c);
        }
        else if (c == ')') {                 // RULE 3: ')' -> pop until '('
            while (!st.empty() && st.top() != '(') {
                postfix += st.top();
                st.pop();
            }
            if (!st.empty()) st.pop();       // discard the '('
        }
        else {                               // RULE 4: operator
            // pop everything with higher-or-equal precedence first
            while (!st.empty() && precedence(st.top()) >= precedence(c)) {
                postfix += st.top();
                st.pop();
            }
            st.push(c);
        }
    }

    // RULE 5: drain whatever is left on the stack
    while (!st.empty()) {
        postfix += st.top();
        st.pop();
    }
    return postfix;
}

int main() {
    string infix = "A+B*(C-D)";
    cout << "Infix   : " << infix << endl;
    cout << "Postfix : " << infixToPostfix(infix) << endl;
    return 0;
}

7.3 🔁 Reverse a String / Check Palindrome

Push every character, then pop them all — they come out backwards. Two lines of logic, one elegant result.

reverse_string.cpp 
#include <iostream>
#include <stack>
#include <string>
using namespace std;

string reverseString(string s) {
    stack<char> st;

    // Step 1: push every character
    for (char c : s) {
        st.push(c);
    }

    // Step 2: pop them all - they come out in reverse order
    string reversed = "";
    while (!st.empty()) {
        reversed += st.top();
        st.pop();
    }
    return reversed;
}

bool isPalindrome(string s) {
    return s == reverseString(s);
}

int main() {
    string word = "racecar";
    cout << "Original  : " << word << endl;
    cout << "Reversed  : " << reverseString(word) << endl;
    cout << "Palindrome: " << (isPalindrome(word) ? "Yes" : "No") << endl;
    return 0;
}

7.4 ↩️ Undo / Redo Feature

undo_demo.cpp 
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int main() {
    stack<string> undoStack;   // every action goes here
    string document = "";

    auto type = [&](string text) {      // helper: simulate typing
        undoStack.push(document);       // save the PREVIOUS state
        document += text;
        cout << "Typed \"" << text << "\"  -> \"" << document << "\"" << endl;
    };

    auto undo = [&]() {                // helper: simulate Ctrl+Z
        if (undoStack.empty()) {
            cout << "Nothing to undo!" << endl;
            return;
        }
        document = undoStack.top();     // restore the previous state
        undoStack.pop();
        cout << "UNDO        -> \"" << document << "\"" << endl;
    };

    type("Hello");
    type(", World");
    type("!");
    undo();     // removes "!"
    undo();     // removes ", World"
    undo();     // removes "Hello"
    undo();     // -> Nothing to undo!

    return 0;
}

📚 Other Classic Stack Applications

  • Function call stack — every function call pushes a stack frame; returning pops it. This is why infinite recursion causes a "stack overflow".
  • Depth-First Search (DFS) — graph/tree traversal uses a stack (or recursion) to remember where to backtrack.
  • Postfix expression evaluation — push operands, and when you hit an operator, pop two, compute, push the result.
  • Backtracking algorithms — mazes, Sudoku solvers, N-Queens.
  • Syntax parsing — compilers and interpreters.
  • Browser history — the back button is literally a stack of URLs.

8 Complexity Summary — The Exam Table

Memorise this table. It appears in every quiz, every midterm, and every interview.

OperationArray-BasedLinked-List-BasedSTL std::stackWhy?
push(x)O(1)O(1)O(1)Just a pointer move / one node insert
pop()O(1)O(1)O(1)Just a pointer move / one node delete
peek() / top()O(1)O(1)O(1)Direct array index or head dereference
isEmpty()O(1)O(1)O(1)One comparison
isFull()O(1)N/AN/AOnly meaningful for fixed-size arrays
size()O(1)O(n)O(1)Array: top+1. Linked list: must walk the chain (unless you keep a counter)
search(x)O(n)O(n)O(n)Stacks are not designed for searching — you must pop to look deeper
💡 The takeaway If your algorithm needs fast search, a stack is the wrong tool. Stacks are brilliant at order-sensitive, one-end-only work: reversing, matching, backtracking, and undo.

🧮 Space Complexity

  • Array-based: O(n) where n is the declared capacity (even if the stack is nearly empty, the memory is reserved).
  • Linked-list-based: O(k) where k is the number of elements currently in the stack — plus 8 bytes of pointer overhead per node.

🧠 Stack — The Whole Idea in 8 Lines
  1. A stack is a linear data structure with one open end called the top.
  2. It follows LIFO: Last In, First Out.
  3. Core operations: push, pop, peek, isEmpty, isFull.
  4. All core operations are O(1).
  5. Array implementation: fast, cache-friendly, but fixed size → can overflow.
  6. Linked-list implementation: dynamic size, but uses extra memory for pointers.
  7. In C++, just use #include <stack> and std::stack<T>.
  8. Used everywhere: undo, browser back, bracket matching, postfix conversion, DFS, function calls.
